Qué se aprende en la carrera

Informática Industrial combina informática, electrónica y automatización para diseñar y mantener sistemas en entornos industriales.

  • Dispositivos inteligentes

    Programación Android para celulares y tabletas.

  • Sistemas informáticos

    Aplicaciones de escritorio en Windows y GNU/Linux, y páginas web con Apache, HTML5, CSS, JavaScript y PHP.

  • Bases de datos

    Modelado, normalización y SQL con SQL Server, MariaDB, Postgres y Oracle.

  • Mantenimiento de equipos

    Hardware y software de computadoras y servidores, e instalación de sistemas operativos.

  • Automatización industrial

    Montaje de sensores y actuadores, lógica cableada y programada, y sistemas SCADA.

  • Redes LAN y WAN

    Diseño, puesta en marcha e interconexión de redes con Mikrotik y Cisco.
